# Evidence checklist

- [ ] Public URL returns successfully and renders the current activity section.
- [ ] Live homepage screenshot with URL visible or recorded in a caption.
- [ ] Specific successful Activity → Pages workflow run URL.
- [ ] Bot/action commit URL whose diff updates README activity markers.
- [ ] Pages settings show GitHub Actions as source.
- [ ] TOKEN secret name is visible; token value never appears.
- [ ] Desktop/mobile build screenshots downloaded from `site-evidence` artifact.
- [ ] A single 6-10 page PDF explains A/E/O evidence, architecture, validation and scheduling rationale.

Record only verified results. Generated build screenshots supplement the live-site screenshot; they do not prove that the public URL is available.
